Neon Shore Cover Studio turns your photos and a caption into a multi-panel GTA-style poster cover — Hero, Duo, Trio and Quad layouts, four Vice City colour grades (Sunset, Neon Night, Golden Hour, Noir), drag-to-position photos, and PNG export in 1080 × 1080, 1080 × 1350 or 1920 × 1080. Fully offline: a static web app, photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Add photos, pick a layout and grade, type a title and tagline, drag each photo into place, and export a PNG.
