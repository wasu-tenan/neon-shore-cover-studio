Neon Shore Cover Studio is an offline web app that turns your own photo and a caption into GTA-style poster cover art: pick a multi-panel layout, drop a photo into each panel, drag to crop and position it, choose a sunset or neon colour grade, letter the title in bold display type with a script accent, and export a share-ready PNG in 1080 × 1080, 1080 × 1350 or 1920 × 1080. No uploads, no network — everything runs from the files in `app/`, with two free sample photos included so you can try it in one click.

## Run it

```sh
node serve.ts
```
